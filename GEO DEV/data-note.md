# Week 2 Data Note

## Dataset 1: Lagos LGA Boundaries

### Dataset
GRID3 NGA – Operational LGA Boundaries

### Source
GRID3 – Geospatial Infrastructure and Demographic Data for Development

Source: https://grid3.org/geospatial-data-nigeria

### Description
This dataset provides country-wide operational Local Government Area (LGA) boundaries in Nigeria at administrative level 2. The dataset was released in March 2021.

### Project Use
The dataset was downloaded and opened in QGIS. The Lagos State LGAs were extracted and exported as a GeoPackage for use as the administrative boundary layer in the building-safety inspection priority analysis.

### Data Information
- Original features: 774 LGAs
- Lagos features: 20 LGAs
- Geometry type: Polygon
- Coverage: Nigeria
- Administrative level: LGA (Level 2)

### Key Columns
- lganame – Local Government Area name
- lgacode – LGA code
- statename – State name
- statecode – State code
- uniq_id – Unique identifier

### Missing Values / Observations
The dataset was inspected in QGIS. No obvious missing values were observed in the main LGA and state identification fields used for the Lagos analysis.
